# Cognivault — Prior-Art & Competitive Positioning

## Purpose

Record relevant prior art so Cognivault does not make unsupported novelty claims.

## Relevant technical prior art

| Work | Relevant overlap | What Cognivault does differently | Claim status |
|---|---|---|---|
| OATutor (CHI 2023) | Open adaptive tutoring, knowledge tracing, BKT-based mastery, adaptive problem selection | Adds evidence-first multimodal source provenance, grounded tutor/assessment verification, misconception signals and a unified evidence-to-learner loop | Established prior art; no novelty claim |
| TutorBench (2025) | Benchmarking tutoring capabilities such as adaptive explanations, feedback and hints | Cognivault uses a course-grounded benchmark plus system-level retrieval, abstention, assessment and personalization tests | Established prior art; informs evaluation |
| Recent pedagogical RAG tutoring work | RAG + learner state + pedagogical response policy | Cognivault targets a lightweight, provenance-first hackathon implementation with explicit fail-closed gates | Strong overlap; no invention claim |
| Commercial AI tutors | Personalized tutoring, practice and progress adaptation | Cognivault emphasizes inspectable source evidence and reproducible evaluation in the demo | Product differentiation hypothesis, not novelty |

## Positioning

Cognivault should be described as an **evidence-first adaptive learning system** whose value comes from integrating:

1. multimodal course-source ingestion,
2. source-addressable evidence,
3. retrieval-first grounded tutoring,
4. explicit unsupported-question abstention,
5. verified assessment generation,
6. interpretable per-topic learner state,
7. misconception signals,
8. targeted next-action recommendations,
9. reproducible evaluation.

These are integrations of established techniques, not claimed inventions.

## Competitive hypothesis

The demo should demonstrate a concrete reliability loop rather than merely listing features:

**source evidence -> grounded answer -> verified assessment -> learner update -> targeted next action -> inspectable evidence**

If later benchmarking shows that this integration materially improves a measured metric over a simpler baseline, that result may be reported as an empirical project contribution.

## Integrity rule

Do not use words such as “first”, “novel”, “unique”, “state-of-the-art”, or “guaranteed” in the final submission unless supported by a documented comparison.
