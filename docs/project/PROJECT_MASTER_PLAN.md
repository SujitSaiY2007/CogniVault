# CogniVault — Project Overview & Plan

**Track:** D — Personalized Tutoring & Adaptive Learning

CogniVault is a course-grounded adaptive learning companion that links evidence retrieval, tutoring, assessment, and learner-state updates.

## Core loop
1. Ingest course sources with provenance and locators.
2. Retrieve relevant evidence.
3. Answer only when the evidence gate permits; otherwise abstain.
4. Verify assessment items and answers within deterministic constraints.
5. Update topic mastery with BKT.
6. Recommend next actions using mastery and prerequisites.
7. Evaluate with reproducible datasets, metrics, and tests.
